About NoteForge

NoteForge is an AI-powered study-platform prototype. This frontend demonstrates study workflows with browser-side sample processing. Production use requires a secure backend, model/API integration, real transcription and file parsers, and an authenticated database. Never place secret API keys in frontend code.
